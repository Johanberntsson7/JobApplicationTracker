 JobApplicationTracker

# Projektbeskrivning

Job Application Tracker är ett konsolprogram som hjälper användaren att hålla koll på sina jobbansökningar. Man kan lägga till ansökningar, uppdatera status (Applied, Interview, Offer, Rejected) och ta bort ansökningar. Programmet kan också visa alla ansökningar, filtrera efter status, och visa statistik, till exempel antal ansökningar och genomsnittlig svarstid. Testa själv!

## Hur man kör programmet 
 När programmet startar möts användaren av en meny med flera val. Användaren skriver en siffra för att välja, till exempel lägga till en ansökan, uppdatera status, visa alla ansökningar, filtrera, visa statistik eller ta bort en ansökan. Använderen kommer även få en summering, om den väljer till exempel "Update application". Har ingen Testdata, så man kommer få lägga till uppgifterna själva. Alltså först "add application (1.).
